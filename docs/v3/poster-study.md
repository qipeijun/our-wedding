# 男方父母版排版精修对照 · 历史试稿（2026-10-21）

## 已确认的试稿范围

用户同意先以男方父母版检验信息区精修：保留招手原片、已选行书标题、完整信息与双二维码，制作前后对照，再判断是否推广到四版。此为首次试稿记录；后续用户选择姓名带减薄、语意分行和标签调整，日程恢复纵向时间轴。当前方案见 `poster-design.md`。

## 排版决定

- 色彩沿用原方案：深酒红 `#852D27`、米白 `#FAF5ED`、正文墨色 `#302426`、辅助暖灰 `#79625E`、细线 `#DDC9BC`。不新增装饰色。
- 姓名、日期、酒店和父母落款使用现有思源宋体子集；邀请正文和赴宴信息使用苹方。称谓16px、姓名27px、正文18px保持原字号，日期26px、酒店25px加强主要信息。
- 姓名带减少上下内边距，称谓更靠近姓名；照片保留完整原比例。
- 邀请正文限制280px行宽，按语意分为四行，避免第一段挤成长行。
- 日期与酒店统一居中，酒店地址完整保留。
- 到场建议作为辅助提示；11点仪式、12点婚宴并列，形成清楚的两个主要时点。具体地点16px、暖灰色，保留完整厅号。
- 父母落款承接时间地点，双码在下方收尾。码图尺寸、模块、静区和颜色保持原值；二维码标签使用暖灰，调整间距。

相比原稿，这版将原有纵向日程改为双列，以完整照片下方的居中邀请结构承接两个正式时点。主要取舍是阅读日程从上到下变为先左后右；对照图用于判断是否更符合正式请柬的阅读感。
