# 图片请帖 · 喜讯入画

## 视觉原则

让喜悦从真实人物开始。原片里的挥手、笑容、花束与完整裙摆构成画面的主角，保留摄影的光影和色彩。标题落在头顶的红色留白里，精细校正字形与人物的距离，让招呼宾客的动作成为整张邀请函的情绪起点。

红与白各有分工。暖红承托照片，深红姓名带承接人物，婚纱白组织邀请与赴宴信息。颜色靠面积和节奏建立联系，二维码使用深酒红码点与适度圆润的定位框，底色与纸面一致，避免在画面末尾突然出现两块白色贴纸。

姓名值得被认真看见。两位新人等重、完整排布；父母版称谓与姓名各成一组，女方版本按女儿在前排列。精工体现在中文字形的重心、关系词与姓名的距离、署名的位置，而不是增加装饰。

信息要有从容的秩序。邀请正文、日期、场地和日程分别形成清楚的阅读组；只保留必要的分隔。把精力放在行宽、字号与空间的逐项推敲上，既保留摄影的视觉分量，也让手机上的宾客容易读到厅号与时间。

高清由真实素材和最终渲染共同保证。3840px宽母版直接读取4000×6000原片；文字用实际字体渲染，全部艺术标题使用矢量轮廓。双二维码按最终像素的整数模块输出。独立1080px分享版重新排版渲染和合成二维码，逐张复核，不能把文件尺寸当作品质验收。
