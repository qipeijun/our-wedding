## 播放与视觉规则

- 配置开关为 `config/wedding.json` 的 `features.backgroundMusic`；仅该布尔值进入页面运行配置。
- 使用带项目子路径的本地MP3。音频 `preload="none"`，首屏资源加载结束后才调用一次 `play()`，浏览器拒绝时静候图标点击，不监听全页触碰，也不使用微信桥接绕过策略。
- 标准音频元素循环播放，不增加音量、播放列表、歌名、唱片图、进度条或装饰动画。此前生成的唱片概念图未用于网页、未进入公开资源。
- 图标固定于版心右上，单音符表示可开启、双竖线表示正在播放可暂停，加载时用小圆环，失败时用划线音符。外层48px触控区域，32px淡米白底、18px深红图标，无边框、无阴影。只有屏幕阅读器读取状态文字。
- 快速点击与迟到的播放Promise不覆盖暂停选择；只根据真实媒体事件显示播放状态。资源错误可主动重试，不轮询重试。
- 手动暂停后不因普通点击、滚动或页面内跳转而恢复。页面隐藏、pagehide、打开高德导航或电话链接前暂停，返回页面不自动恢复。
- 复制地址弹层打开时隐藏音乐按钮，避免在模态内容之外留下可点击入口；原有音乐状态不因打开复制弹层改变。
