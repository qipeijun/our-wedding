## 播放与视觉规则

- 配置开关为 `config/wedding.json` 的 `features.backgroundMusic`；仅该布尔值进入页面运行配置。
- 使用带项目子路径的本地MP3，音频 `preload="none"`。没有交互时在首屏加载结束后自动尝试一次；真实页面 `touchend` 或 `click` 可直接触发首播尝试，不等待定时器、不使用微信桥接。浏览器拒绝时仍保留音符入口。
- 页面手势只负责首次开启。播放成功、暂停或资源错误后移除全页监听，不覆盖宾客的暂停选择。音符按钮使用自身点击逻辑，导航与拨号优先暂停；历史返回时不重新注册首播手势。单纯滚动不保证被浏览器接受为播放授权。
- 标准音频元素循环播放，不增加音量、播放列表、歌名、唱片图、进度条或装饰动画。此前生成的唱片概念图未用于网页、未进入公开资源。
- 图标固定于版心右上并向内留白；桌面端计入封面顶部32px留白，避免跨在封面边缘。单音符表示可开启、双竖线表示正在播放可暂停，加载时用小圆环，失败时用划线音符。保留48px透明触控区域，仅显示18px暖铜色细线图标，无圆底、边框或阴影。只有屏幕阅读器读取状态文字。
- 快速点击与迟到的播放Promise不覆盖暂停选择；只根据真实媒体事件显示播放状态。资源错误可主动重试，不轮询重试。
- 手动暂停后不因普通点击、滚动或页面内跳转而恢复。页面隐藏、pagehide、打开高德导航或电话链接前暂停，返回页面不自动恢复。
- 首播前临时隐藏（含后台打开、首次加载尚未完成）只取消当前播放请求，仍保留页面手势唤起；回到前台不会自行播放，需下一次真实点击或触摸。已播放、主动暂停、离站及历史返回继续仅由音符按钮恢复。
- 复制地址为页内操作，不改变音乐状态。
