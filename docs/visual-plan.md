## 视觉方向

以两人挥手迎宾为开场，暖红背景的负空间承载「囍」。不额外绘制传统纹样，不以英文或刊号装饰。红底中式合影只用一张，作为邀请章节的礼仪重心。摄影从红色转向中性灰，再进入自然光，最后以暖红收束。绿色仅来自真实户外摄影，不成为界面配色。

色彩：喜红 `#92352E`、照片暖红（保留原色）、纸白 `#F4EBDD`、深棕 `#392D2B`、米金 `#B49A78`。标题优先本地宋体/明朝体；正文为系统中文黑体，不下载来源或授权不明的字体。视觉记忆点是挥手照片上方的克制大「囍」字，而非全页装饰。

布局比较：全屏强制 cover 会在细长手机上切去两侧裙摆，因此采用原比例完整照片 + 独立红底姓名区域；全屏感由连续红色画布形成，不强行把 2:3 照片裁成 9:19.5。图库以双图—通栏—远景—竖幅节奏，避免连续大头像。

## 改片方式与验收

修改 `src/config/photos.ts` 的文件名、alt、顺序、布局和焦点，再运行图片生成脚本。所有模块默认按原比例显示，不以裁切解决适配问题。封面文字必须重新核对新图留白；换片后需重新截图验收，不能保证任意图片都适合既有文字区域。

检查 320 / 375 / 390 / 430px 和桌面：人物头手与服装未被 CSS 裁掉、图像不变形、标题不压脸、页面没有横向溢出。实际验收结果见 `docs/verification.md`。
