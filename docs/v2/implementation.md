## 自检中的修正

1. 初版正文自然换行拆开“诚挚”“我们”，改为定稿逗号处的软换行，文案字符未变。
2. 复制失败后原按钮仍可能处于Vue尚未刷新的disabled状态，补充等待DOM更新再保存触发焦点，关闭弹层可以准确返回。
3. 浏览器原生焦点恢复早于dialog的close事件，测试改为等待焦点与滚动状态都恢复，不把异步时序当成通过。
4. tsx对测试注入函数添加名称辅助函数，导致浏览器上下文没有该辅助函数；剪贴板模拟改为明确的浏览器JavaScript片段，生产页面不添加额外兜底。
5. 旧预览服务基路径为根路径，子路径请求曾返回HTML回退；修改base后重启同一预览服务，完整检查实际资源类型与字体。
